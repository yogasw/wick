Roadmap
Fase 1
Tool + 2 adapter. ImageGen interface, openai + gemini, Modality field, MCP handler, Artifact output, Test button per-model, cap n.
Fase 2
UI manual. internal/tools/image-gen/ tipis (form prompt → hasil) yang memanggil wick.ImageGen — bukan implement HTTP sendiri. Dua permukaan, satu core.
Fase 3
image-to-image / edit + mask. Butuh input attachment, bukan cuma prompt.
Fase 4
provider-storage sink. Hasil ke S3/lokal supaya URL tahan lama, bukan cuma dalam session dir.
⏸ ditahan
Video / audio gen. Jangan generalisasi ImageGen → MediaGen sebelum ada use-case kedua yang nyata.
Sengaja ditolak
Menumpang LLM.GenerateContent dengan part khusus — memaksa T2I ke bentuk percakapan bikin adapter text kotor, dan streaming semantics tak berlaku.
Provider TypeImage baru — provider = runner percakapan; image gen tak punya turn/history/tools.
Base64 di tool result — satu PNG 1024² ≈ ratusan KB base64 membanjiri context, dan imagecard tak bisa render.
Module internal/tools/text-to-image/ di fase 1 — duplikat key management + model list yang sudah ada di WickModel. User isi API key dua kali untuk vendor yang sama.
