## Penyebab dominan per hotspot
- **`internal/mcp/handlers/tools.go`**: mayoritas (54+26+7 dari sample) adalah string literal (`"string"`, `"object"`, `"array"`) untuk JSON-schema yang escape tiap kali handler dipanggil — karena dipakai lewat `interface{}`/`any` saat build schema map. Ini yang paling masuk akal untuk dioptimasi (precompute sekali di package init, bukan per-request).
- **`internal/pkg/api/server.go`**: leaking param `sessionID`, `ctx`, `ev` — closure/handler pattern, ctx & event dipakai standard di seluruh call chain, escape wajar.
- **`internal/tools/agents/handler.go`**, **`internal/connectors/workflow/ops.go`**, **`internal/admin/handler.go`**: dominan "leaking param content" pada `c`, `h`, `r`, `w` — ini receiver/handler HTTP (echo/net-http style), pointer ke context/writer wajib escape karena interface method dispatch. Bukan bug, struktural.
- **`internal/connectors/repo.go`** dan repo-layer lain (`internal/admin/repo.go`, `internal/tags/repo.go`, `internal/oauth/repo.go`, dst): dominan `moved to heap` untuk struct hasil query (`cfg`, `r`, `s`) — pointer dikembalikan ke caller, escape wajib karena lifetime keluar dari fungsi. Idiomatic Go repo pattern, no action needed.

## Kesimpulan
- Tidak ada compile error nyata di module utama. `go build -gcflags='-m' ./...` gagal cuma karena `template/` adalah scaffold folder yang bukan bagian valid module (import path `template/...` tanpa prefix module) — sudah di-exclude, tidak perlu fix kecuali `template/` memang dimaksudkan buildable (kalau iya, perlu prefix import jadi `github.com/yogasw/wick/template/...`).
- Escape analysis overall sehat: proporsi heap-escape besar didominasi pattern struktural yang memang wajib escape di Go (interface dispatch di HTTP handler, pointer return dari repo/DB layer, JSON-schema built dari `any`). Tidak ada red flag GC-pressure yang jelas di luar pola normal.
- Satu titik optimasi nyata kalau dibutuhkan: `internal/mcp/handlers/tools.go` — schema string literal bisa di-precompute sekali (package-level var) daripada dibangun ulang tiap request/tool-list call.
