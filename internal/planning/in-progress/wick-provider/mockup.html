Wick runs in-process with native tools: shell (bash/cmd — gate rules enforced inside the tool itself, no hook probe needed) and wick connectors (direct service call, no MCP round-trip).

Row actions are a single ⋯ menu (click to preview above) — Edit / Set default / Test / Duplicate / Disable-Enable / Delete — instead of separate buttons, so the row stays a fixed width as more actions land later. A Disabled model (bottom row) is greyed out, drops out of the composer's model submenu (View 4) and can't be set default or tested until re-enabled, but stays in the table so its config isn't lost.
